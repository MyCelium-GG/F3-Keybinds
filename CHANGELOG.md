# Changelog

All notable changes to F3 Keybinds are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
F3 Keybinds is versioned semantically (`MAJOR.MINOR.PATCH`).
It runs on Minecraft 26.3, 26.2 and 26.1 (Fabric + Forge + NeoForge, Java 25) and requires
[Mycel](https://github.com/MyCelium-GG/MyCel-Lib) (`my.celium.org`).

## [1.0.0] - 2026-11-20

### Added
- A key of its own for every F3 shortcut, in Controls under Debug: chunk borders, hitboxes, advanced tooltips, reload chunks, reload resource packs, clear chat, copy location, copy data, game mode switcher, cycle spectator, debug options, lost focus pause, profiling, the charts, the lightmap texture, the dumps and (on 26.3) improved transparency. They work without holding F3 and start unbound.
- The game mode switcher works with one key: press it again for the next mode, Enter, Space or a click to pick. The hint shows your key.
- Installed without Mycel, the game still starts: the mod stays off and tells you in chat that Mycel is missing, with a download link.
- 11 languages.
